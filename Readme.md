# Приём заявок
Стек: Только валидный HTML5 и CSS3 (без JS, внешних библиотек и веб-шрифтов)

 1. Структура страниц
• Шапка (фиксированная): Логотип слева, навигация из 4 ссылок справа («Главная», «О нас», «Услуги», «Контакты»).
• Первый экран (Hero): Заголовок H1, подзаголовок, краткий текст, кнопка «Начать работу».
• Блок «Наши возможности»: Заголовок + от 4 карточек.  
• *Состав карточки:* синяя иконка/эмодзи, заголовок, описание, мелкая подпись.
• Подвал (Footer): Текст копирайта по центру
2. Дизайн и интерактив
• Цвета (в CSS-переменных): 
• Фон страницы — светло-серый.
• Карточки — белые.
• Текст — тёмно-серый.
• Акцент (кнопка, иконки, ссылки) — синий.
• Типографика: Системные шрифты (без внешних подключений).
• Hover-эффекты: Смена цвета у кнопки; легкий подъем и мягкая тень у карточек.
3. Технические требования и адаптивность
• Полная адаптивность: от 320px до 1920px, без горизонтального скролла.
• Сетка карточек: на ПК — многоколоночная сетка, на мобильных — 1 колонка.
• Чистый, легко масштабируемый код для быстрой замены текстов и добавления новых блоков.
